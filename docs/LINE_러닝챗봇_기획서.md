## 1. 프로젝트 개요

### 배경 및 목적
LINE 러닝 동호회 그룹챗 활성화를 위해 스크린샷 기반 러닝 인증, 출석 관리, 랭킹, 두 가지 선물 이벤트를 통합 제공하는 챗봇 시스템.

- 기존 러닝 앱(Nike Run / Strava / 가민 등) 그대로 사용 — 앱 변경 불필요
- 스크린샷 한 장으로 거리·시간·페이스 자동 추출 및 출석 인증 동시 처리
- 주간 개근 이벤트 + 관리자 지정 하루 랭킹 이벤트 두 트랙으로 참여 동기 극대화

### 기대 효과
- 그룹챗 일일 메시지 수 증가 (목표: 현재 대비 +40%)
- 러닝 참여율 향상 — 스크린샷 인증이 곧 활동 인증 역할
- 두 가지 이벤트를 통한 자발적 바이럴 및 신규 멤버 유입
- 데이터 기반 러닝 습관 형성 지원

## 2. 스크린샷 인증 시스템

### 2.1 전체 흐름

```
그룹챗에 스크린샷 업로드
         ↓
LINE Webhook → 이미지 URL 수신
         ↓
Claude Vision API로 OCR 처리
  → 거리 / 시간 / 페이스 / 날짜 추출
         ↓
이상치 필터링 검사
         ↓
챗봇이 확인 메시지 전송
  ┌─────────────────────────┐
  │ 📊 기록을 확인해주세요!  │
  │ 거리:  5.2 km           │
  │ 시간:  28분 14초         │
  │ 페이스: 5'26"/km        │
  │ 날짜:  2025-03-10       │
  │                         │
  │  ✅ 맞아요  │ ❌ 틀려요  │
  └─────────────────────────┘
         ↓ ✅ 확인
DB 저장 → 출석 체크 → 랭킹 업데이트
         ↓
결과 카드 그룹챗 발송
```

> **확인 → DM 처리 방식 권장**
> 그룹챗에서 업로드 → 확인 메시지는 개인 DM으로 전송 → 그룹챗 피드 오염 방지

### 2.2 스크린샷 필수 포함 정보

| 항목 | 필수 여부 | 용도 |
|------|----------|------|
| 📅 날짜 (연/월/일) | ✅ 필수 | 당일 기록 여부 검증 |
| 📏 거리 (km) | ✅ 필수 | 월간 누적 거리 집계 |
| ⏱ 소요 시간 | ✅ 필수 | 페이스 자동 계산 |
| 🏃 평균 페이스 (min/km) | ✅ 필수 | 랭킹 지표 |
| 🗺 경로 지도 | ⭐ 선택 | 신뢰도 향상 (+보너스) |
| 앱 로고/워터마크 | ⭐ 선택 | 앱 출처 자동 식별 |

### 2.3 지원 앱

| | | | |
|---|---|---|---|
| ✅ Nike Run Club | ✅ Strava | ✅ 가민 Connect | ✅ 애플 피트니스 |
| ✅ 삼성 헬스 | ✅ Adidas Running | ✅ Runkeeper | ✅ 카카오맵 |

### 2.4 이상치 필터링 규칙

- **거리**: 0.5km 미만 또는 100km 초과 → 재확인 요청
- **페이스**: 2'00"/km 미만(너무 빠름) 또는 20'00"/km 초과 → 경고
- **날짜**: 당일(자정 기준 24시간 이내) 기록만 인정, 소급 불가
- **중복**: 동일 날짜 동일 시간대 기록은 1건만 인정

### 2.5 ❌ 오류 시 처리

```
유저가 ❌ 틀려요 탭
       ↓
"어떤 항목이 잘못됐나요?"
  1️⃣ 거리  2️⃣ 시간  3️⃣ 페이스  4️⃣ 날짜
       ↓
유저가 직접 수정 입력
       ↓
다시 확인 메시지 → 저장
```

## 3. 출석체크 시스템

### 3.1 출석 인증 조건

> 스크린샷 인증 성공 = 당일 출석 자동 체크 (별도 명령어 없음)

| 조건 | 내용 |
|------|------|
| 1일 최대 인정 | 1회 (중복 업로드 시 첫 번째만 출석 인정) |
| 최소 거리 | 1.0km 이상 |
| 인증 마감 시간 | 당일 23:59까지 업로드된 기록만 인정 |
| 그룹챗 공유 | 출석 체크 시 그룹챗에 자동 공유 |

### 3.2 출석 배지 시스템

| 배지 | 이름 | 조건 | 효과 |
|------|------|------|------|
| 🔥 | 불꽃 런너 | 3일 연속 출석 | 그룹챗 이름 옆 배지 표시 |
| ⚡ | 번개 런너 | 7일 연속 출석 | 랭킹 카드 특별 테두리 |
| 🌟 | 스타 런너 | 30일 누적 출석 | 명예의 전당 등재 |
| 👑 | 왕관 런너 | 한 달 개근 (월 전체) | 다음 달 랭킹 보너스 +5점 |

## 4. 랭킹 시스템

### 4.1 랭킹 점수 산식

```
종합 점수 = (정규화 거리 × 0.6) + (정규화 페이스 점수 × 0.4)
```

| 지표 | 가중치 | 산정 방법 |
|------|--------|---------|
| 총 누적 거리 (km) | 60% | 월간 전체 세션 거리 합산 |
| 평균 페이스 (min/km) | 40% | 빠를수록 높은 점수 (역산) |

- 정규화: 각 지표를 그룹 내 최댓값 대비 백분율로 변환
- 페이스 점수 = (그룹 내 최저 페이스 / 개인 페이스) × 100

### 4.2 랭킹 카드 예시 (Flex Message)

```
🏆  이번 달 러닝 랭킹  (2025년 3월)
──────────────────────────────
🥇 1위  김철수    42.3km  5'12"/km
🥈 2위  이영희    38.1km  5'28"/km
🥉 3위  박민준    35.7km  5'45"/km
   4위  최지은    30.2km  6'10"/km
──────────────────────────────
📅 마감: 3월 31일  |  /랭킹 으로 확인
```

## 5. 이벤트 시스템

두 가지 이벤트가 동시 운영되며, 같은 날 스크린샷 하나로 출석 + 개근 + 하루 이벤트 모두 처리됩니다.

---

### 5.1 이벤트 A — 주간 개근 챌린지 🗓

> **매주 월~일 7일 모두 뛰면 선물!**

| 항목 | 내용 |
|------|------|
| 기간 | 매주 월요일 00:00 ~ 일요일 23:59 |
| 달성 조건 | 해당 주 7일 모두 스크린샷 인증 완료 |
| 선물 대상 | 7일 개근 달성자 **전원** (복수 수상 가능) |
| 선물 지급 | 익주 월요일 오전 9시 챗봇 자동 발표 + DM 발송 |
| 연속 보너스 | 2주 연속 개근 시 추가 선물 또는 배지 지급 |

**매일 저녁 8시 자동 발송되는 주간 현황 메시지:**

```
📅  이번 주 개근 현황  (3/10 월 ~ 3/16 일)
─────────────────────────────────────
김철수   ✅월 ✅화 ✅수 ✅목 ✅금 ⬜토 ⬜일   5/7
이영희   ✅월 ✅화 ✅수 ✅목 ✅금 ✅토 ⬜일   6/7
박민준   ✅월 ✅화 ✅수 ✅목 ✅금 ✅토 ✅일   7/7 🔥
─────────────────────────────────────
🏆 오늘도 달리면 개근까지 1일 남았어요!
```

---

### 5.2 이벤트 B — 하루 페이스 랭킹 이벤트 ⚡

> **관리자가 지정한 단 하루! 그날 가장 빠른 사람이 우승!**

| 항목 | 내용 |
|------|------|
| 랭킹 기준 | 당일 평균 페이스 1위 (min/km, 빠를수록 유리) |
| 이벤트 지정 | 관리자가 날짜 지정 → 챗봇이 D-3, D-1, 당일 공지 |
| 참여 방법 | 이벤트 당일 스크린샷 인증 시 **자동 참여** (별도 신청 불필요) |
| 우승자 | 당일 23:59 마감 후 페이스 1위 1명 |
| 동점 처리 | 페이스 동일 시 먼저 인증한 사람 우선 |
| 결과 발표 | 익일 오전 9시 챗봇이 그룹챗에 결과 카드 발송 |

**공지 자동화 흐름:**

| 시점 | 내용 |
|------|------|
| D-3 | 🔔 "이번 주 토요일은 스피드 데이 이벤트!" 예고 |
| D-1 | ⚡ "내일이 이벤트 당일! 컨디션 관리 잘 하세요" |
| 당일 00:00 | 🏁 "오늘이 하루 랭킹 이벤트 당일! 스크린샷 잊지 마세요" |
| 당일 18:00 | 📊 현재 중간 순위 발표 (참여 독려) |
| 익일 09:00 | 🏆 최종 우승자 발표 + 결과 카드 |

## 7. 데이터 모델

### 7.1 running_sessions (러닝 세션)

```sql
CREATE TABLE running_sessions (
  session_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id          VARCHAR NOT NULL,       -- LINE User ID
  group_id         VARCHAR NOT NULL,       -- LINE Group ID
  run_date         DATE NOT NULL,          -- 러닝 날짜 (스크린샷 기준)
  distance_km      FLOAT NOT NULL,         -- 거리 (km)
  duration_sec     INTEGER NOT NULL,       -- 소요 시간 (초)
  pace_min_per_km  FLOAT NOT NULL,         -- 평균 페이스 (min/km)
  screenshot_url   VARCHAR,               -- 원본 스크린샷 경로
  source_app       VARCHAR,               -- 인식된 앱명
  is_attendance    BOOLEAN DEFAULT true,  -- 출석 인정 여부
  event_id         UUID,                  -- 하루 이벤트 참여 시 연결 ID
  created_at       TIMESTAMP DEFAULT now()
);
```

### 7.2 member_stats (멤버 통계)

```sql
CREATE TABLE member_stats (
  user_id              VARCHAR PRIMARY KEY,
  display_name         VARCHAR NOT NULL,
  monthly_distance_km  FLOAT DEFAULT 0,
  monthly_avg_pace     FLOAT,
  weekly_attendance    INTEGER DEFAULT 0,  -- 이번 주 출석 일수 (0~7)
  streak_days          INTEGER DEFAULT 0,  -- 현재 연속 출석 일수
  badges               TEXT[],             -- 보유 배지 목록
  ranking_score        FLOAT DEFAULT 0,
  updated_at           TIMESTAMP DEFAULT now()
);
```

### 7.3 events (이벤트)

```sql
CREATE TABLE events (
  event_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  event_type     VARCHAR NOT NULL,   -- 'WEEKLY_ATTENDANCE' | 'DAILY_RACE'
  event_date     DATE,               -- 하루 이벤트 날짜 (B타입만)
  week_start     DATE,               -- 주간 이벤트 시작일 (A타입만)
  created_by     VARCHAR NOT NULL,   -- 관리자 LINE ID
  status         VARCHAR DEFAULT 'SCHEDULED',  -- SCHEDULED | ACTIVE | CLOSED
  winner_user_id VARCHAR,            -- 우승자 ID (마감 후 기록)
  created_at     TIMESTAMP DEFAULT now()
);
```

## 8. 기술 스택

| 레이어 | 기술 | 역할 |
|--------|------|------|
| 챗봇 플랫폼 | LINE Messaging API | 그룹챗 메시지 수신·발신, 이미지 수신 |
| 이미지 분석 | **Claude Vision API** | 스크린샷 OCR, 수치 추출 |
| 백엔드 | **Node.js + TypeScript** | 웹훅 처리, 랭킹·이벤트 로직 |
| 데이터베이스 | **PostgreSQL** (Supabase) | 세션, 출석, 이벤트, 랭킹 저장 |
| 스케줄러 | Cron Job (node-cron) | 주간 개근 집계, 이벤트 공지 자동화 |
| 호스팅 | Render.com / Railway | 저비용 배포 |
| 이미지 저장 | AWS S3 / Supabase Storage | 스크린샷 원본 보관 |
